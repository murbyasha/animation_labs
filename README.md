Программа представляет собой модульное графическое приложение на Python, разработанное в рамках проектного практикума. В приложении реализованы две лабораторные работы: первая — построение фрактального дерева с возможностью динамического управления углом через слайдер[cite: 5], вторая — сложная анимация деформации круга в треугольник с использованием полярных координат[cite: 3]. Предусмотрен удобный интерфейс с переключением режимов работы.

## Функциональные возможности

* **Лабораторная №1 (Фрактал):**
  * Построение рекурсивного фрактального дерева (до 10 итераций)[cite: 5, 6].
  * Интерактивная регулировка угла ветвления с помощью слайдера в реальном времени[cite: 5, 6].
* **Лабораторная №2 (Анимация круга):**
  * Плавная покадровая анимация превращения окружности в треугольник на базе полярных координат[cite: 3, 6].
  * Управление воспроизведением: пауза (клавиша `Space`) и сброс параметров (клавиша `R`).

## Требования к системе

* **Python:** 3.9 или выше
* **Операционная система:** Windows / macOS / Linux[cite: 4]
* **Библиотеки:** `tkinter` (встроенная в Python)[cite: 4]
